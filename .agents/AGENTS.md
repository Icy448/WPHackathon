# Project Guidelines & Agent Skills

This project is a Westpac Online Banking prototype built with GEL design system conventions.

## Available Agent Skills

The following skills from [`WestpacGEL/GEL-next`](https://github.com/WestpacGEL/GEL-next) are available in `.agents/skills/`:

### Westpac GEL Consumer Skills
- **`using-westpac-ui`** (`.agents/skills/using-westpac-ui/SKILL.md`): Component usage guidance, capabilities, responsive variants, brand theming, and full reference catalog for `@westpac/ui`.
- **`installing-westpac-ui`** (`.agents/skills/installing-westpac-ui/SKILL.md`): Setup and installation guide for `@westpac/ui`, `@westpac/style-config`, Tailwind CSS v4, and brand font setup.
- **`migrating-to-westpac-ui-v1`** (`.agents/skills/migrating-to-westpac-ui-v1/SKILL.md`): Migration procedures, codemods, and breaking changes when migrating to `@westpac/ui` v1.x.

### Web & React Best Practices
- **`vercel-react-best-practices`** (`.agents/skills/vercel-react-best-practices/SKILL.md`): Performance optimizations, server/client component guidelines, rendering efficiency, and React patterns.
- **`web-design-guidelines`** (`.agents/skills/web-design-guidelines/SKILL.md`): Review UI code for Web Interface Guidelines and accessibility compliance.

### GEL Component Development Skills
- **`creating-gel-component`** (`.agents/skills/creating-gel-component/SKILL.md`): Scaffolding and component authoring workflow following GEL design system standards.
- **`reviewing-gel-component`** (`.agents/skills/reviewing-gel-component/SKILL.md`): Convention compliance checklist for GEL components.
- **`writing-gel-tests`** (`.agents/skills/writing-gel-tests/SKILL.md`): Vitest + React Testing Library patterns and accessibility testing.
